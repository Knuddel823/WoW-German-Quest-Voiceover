# German Quest Voiceovers for Chatty Little NPC

An unofficial German quest voiceover add-on for [Chatty Little NPC](https://github.com/mantaskazlauskas/ChattyLittleNpc).

## Version 0.1.0

This is an early release with **partial German quest coverage**. It includes 12,398 German voice recordings; not every World of Warcraft quest is voiced yet. When a German recording is unavailable, Chatty Little NPC can use the English recording if English fallback is enabled.

## Installation

1. Install and enable Chatty Little NPC.
2. Download and extract the German voiceover release archive.
3. Copy the `ChattyLittleNpc_Vanilla_deDE_voiceovers` folder into the `Interface/AddOns` folder for your WoW game version.
4. Restart the game or type `/reload`.
5. In Chatty Little NPC's **Language** settings, select **German (deDE)**. Enable English fallback if you want English recordings for quests without a German recording.

## Notes

- The German recordings are installed as a separate add-on. Updates to the original English voiceover add-on do not overwrite them.
- Version 0.1.0 contains quest voiceovers.
- This is an unofficial fan project. It is not affiliated with or endorsed by Blizzard Entertainment or the Chatty Little NPC maintainer.
