# German Quest Voiceovers for Chatty Little NPC

An unofficial German quest voiceover add-on for [Chatty Little NPC](https://github.com/mantaskazlauskas/ChattyLittleNpc).

## Version 0.2.0

This release contains **13,929 German voice recordings** for quests in **WoW Classic Era** and **WoW Forever**, including many of the new quests added in WoW Forever.

Coverage is still **partial**: not every quest is voiced yet. When a German recording is unavailable, Chatty Little NPC can use the English recording if English fallback is enabled.

Descriptive passages in quest texts (for example *"Ello looks at the letter."*) and quests that start or end at an object, such as a book or a corpse, are read by a narrator voice. Everything else is spoken by a voice that matches the quest giver.

## Installation

1. Install and enable Chatty Little NPC.
2. Download and extract the German voiceover release archive.
3. Copy the `ChattyLittleNpc_Vanilla_deDE_voiceovers` folder into the `Interface/AddOns` folder of your game version (for example `_classic_era_` or `_forever_`).
4. Restart the game or type `/reload`.
5. In Chatty Little NPC's **Language** settings, select **German (deDE)**. Enable English fallback if you want English recordings for quests without a German recording.

When updating from an older version, delete the old `ChattyLittleNpc_Vanilla_deDE_voiceovers` folder first, so that removed recordings don't remain.

## Notes

- The German recordings are installed as a separate add-on. Updates to the original English voiceover add-on do not overwrite them.
- This version contains quest voiceovers only (quest description, progress and completion). Gossip, item and object texts are not voiced yet.
- This is an unofficial fan project. It is not affiliated with or endorsed by Blizzard Entertainment or the Chatty Little NPC maintainer.
